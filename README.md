# Primeros pasos en Claude Code

Este es un repositorio de práctica para aprender a usar **Claude Code**, la herramienta de línea de comandos de Anthropic para trabajar con IA sobre proyectos de código.

La idea es usar este repo como sandbox: probar comandos, pedirle cambios a Claude Code, ver cómo edita archivos, crea commits, etc., sin miedo a romper nada importante.

## Contenido

- `index.html`: una página web simple con un contador que suma de a uno cada vez que apretás un botón. Sirve como ejemplo de una primera tarea hecha con Claude Code.

## Cómo probar el contador

Abrí el archivo `index.html` en cualquier navegador (doble clic alcanza, no hace falta servidor).
